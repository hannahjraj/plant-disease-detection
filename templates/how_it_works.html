Deep Learning Architecture

How The System Works

An end-to-end overview of the Convolutional Neural Network pipeline from raw RGB leaf inputs to disease classification.

1

Upload Leaf Image

The user provides a high-resolution photograph of a healthy or symptomatic plant leaf via drag-and-drop or file selector. The client validates the file against supported MIME types (JPG, PNG, WEBP) and ensures file limits (<16 MB).

2

Image Preprocessing & Rescaling

The image is decoded using PIL into an RGB channel matrix, dynamically resized to a standardized input resolution of 128 × 128 pixels, and scaled using a Rescaling(1./255) layer to normalize pixel intensity ranges from [0, 255] to floating-point values [0.0, 1.0].

img_resized = img.resize((128, 128))
tensor = np.expand_dims(np.array(img_resized, dtype=np.float32), axis=0)
3

Convolutional Layers & Feature Extraction

Four sequential 2D Convolutional blocks apply learnable kernels (3×3 receptive filters) across the spatial dimensions:

  • Block 1 (32 Filters): Captures low-level spatial features such as edges, leaf boundaries, and basic veins.
  • Block 2 (64 Filters): Detects textural variations, spot perimeters, and circular discoloration patterns.
  • Block 3 & 4 (128 & 256 Filters): Extracts high-level lesion morphology, bullseye rings, concentric necrosis, and pustule shapes.
layers.Conv2D(32, (3, 3), padding="same", activation="relu"),
layers.BatchNormalization(),
layers.MaxPooling2D((2, 2))
4

Batch Normalization, Pooling & Dropout

Each convolutional block includes Batch Normalization to stabilize gradient descent and MaxPooling to reduce spatial dimensions while retaining invariant dominant activations. A Dropout layer (0.4) prevents overfitting by randomly deactivating neurons during training.

5

Global Pooling & Dense Classification Head

A GlobalAveragePooling2D layer aggregates spatial feature maps into a dense 1D embedding vector, passed through a fully connected Dense layer (128 units with ReLU activation) before feeding into the final output layer.

6

Softmax Output & Diagnostic Recommendations

The final dense layer applies the Softmax activation function to output a normalized probability distribution across all trained plant classes. The index with maximum probability determines the predicted diagnosis, and the system delivers actionable, organic cultural management instructions.

confidence = np.max(predictions[0]) * 100.0
predicted_class = class_names[np.argmax(predictions[0])]
