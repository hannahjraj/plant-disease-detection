Academic Project Overview

About The System

A comprehensive deep learning framework engineering precision agricultural diagnostics for smart farming.

1. Project Abstract & Motivation

Plant diseases pose a severe threat to global food security, causing agricultural yield reductions of 20% to 40% globally each year. Traditional manual diagnosis by agronomists is labor-intensive, slow, and often inaccessible to smallholder farmers in remote farming regions.

This academic project presents an automated, computer-vision-based diagnostic system employing a deep Convolutional Neural Network (CNN) implemented via TensorFlow/Keras and served through a lightweight, modular Python Flask web interface. The system accurately classifies leaf abnormalities from digital photographs, computes confidence percentages, and delivers instant, non-chemical advisory actions.

2. Project Objectives

Automated Feature Extraction

Eliminate handcrafted feature engineering by leveraging autonomous spatial convolutional filters.

Dynamic Dataset Adaptation

Allow the model to dynamically detect any number of classes directly from folder structures without hardcoding.

Empirical Validation

Record genuine validation accuracy, loss curves, and confusion matrix tables rather than hypothetical claims.

User-Friendly Accessibility

Provide a clean, modern web interface with zero framework bloat, optimized for both desktop and mobile screens.

4. Academic Viva & Defense FAQ

Q1: Why use a CNN instead of traditional machine learning (e.g. SVM or Random Forest)?

Traditional ML requires manual feature engineering (such as calculating color histograms, Haralick texture features, or SIFT descriptors). CNNs automatically learn hierarchical spatial features directly from raw image pixels through backpropagation, capturing intricate lesion textures more effectively.

Q2: What is the role of Batch Normalization?

Batch Normalization stabilizes internal covariate shift across layers, accelerates model convergence, and acts as a mild regularizer, allowing higher learning rates without divergence.

Q3: How does the system handle novel or custom datasets?

train_model.py automatically inspects the dataset/ directory for class subfolders, computes the number of output units, configures the Softmax classification layer dynamically, and exports class_names.json for seamless integration with Flask.
